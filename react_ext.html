useEffectの基本

import { useEffect, useState } from 'react';

function App() {
  const [data, setData] = useState([]);

無限レンダリング

useEffectの依存配列を書き忘れたり、レンダリング中に直接状態を更新したりすると、コンポーネントが無限に再描画されてブラウザがフリーズします。

REACT 
// ❌ 無限ループの罠
function BadCounter() {
  const [count, setCount] = useState(0);
  
  // レンダリングされるたびに呼ばれ、さらにレンダリングを引き起こす
  // setCount(count + 1);
  
  return 
{count}
;
}

Stateの直接変更

Reactは「オブジェクトの参照が変わったか」で再描画を判定します。配列にpushしても参照は変わらないため、画面が更新されません。

REACT 
// ❌ Stateの直接変更（画面が更新されない）
// list.push('new item');
// setList(list);

// ✅ スプレッド構文で新しい配列を作る
setList([...list, 'new item']);
