💡 既存の型をパズルのように変形して使い回す

Partial, Omit, Pick

「あの型のIDだけ抜いた型が欲しい」「全ての項目を任意（?）にした型が欲しい」といった実務の要求に、一瞬で応えることができる組み込みの機能です。

TYPESCRIPT 
interface User {
  id: number;
  name: string;
  email: string;
  age?: number;
}

// Partial: すべてのプロパティを任意（?付き）にする
type UpdateUserDto = Partial;

// Omit: 指定したプロパティ（id）だけを除外する
type CreateUserDto = Omit;

// Pick: 指定したプロパティ（name, email）だけを抽出する
type ContactInfo = Pick;

上級編: 型ガードと絞り込み（Type Narrowing）

▼

💡 不確実なデータを安全な型に「確定」させる

ユーザー定義型ガード

APIから取得した unknown なデータが、本当に目的の型（Interface）を満たしているかを実行時にチェックし、TypeScriptに「これは安全だ」と教えます。

TYPESCRIPT 
interface Bird {
  fly: () => void;
}

// 戻り値の「obj is Bird」が型ガードの印
function isBird(obj: any): obj is Bird {
  return obj !== null && typeof obj.fly === 'function';
}

function move(animal: unknown) {
  if (isBird(animal)) {
    // ここに入ると animal は完全に Bird 型として扱われる
    animal.fly();
  } else {
    console.log('飛べません');
  }
}
