💡 複雑なロジックを切り出してコンポーネントをスッキリさせる

ロジックの再利用

APIの取得処理や、ローカルストレージの管理など、複数のコンポーネントで使い回す処理を「自分専用のHook（use○○）」として独立させます。

REACT 
import { useState, useEffect } from 'react';

// カスタムフックの定義
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch(url).then(res => res.json()).then(data => {
      setData(data);
      setLoading(false);
    });
  }, [url]);

  return { data, loading };
}

上級編: パフォーマンス最適化（メモ化）

▼

💡 不要な再レンダリングを防ぎ、アプリを高速に保つ

useMemo と useCallback

Reactは親が再描画されると子も全て再描画されます。重い計算結果を保存する useMemo や、関数の再生成を防ぐ useCallback を使いこなすとプロレベルに近づきます。

REACT 
import { useState, useMemo, useCallback } from 'react';

function HeavyComponent({ list }) {
  // listが変わらない限り、この重いソート処理はスキップされる
  const sortedList = useMemo(() => {
    return list.sort((a, b) => b.score - a.score);
  }, [list]);

  // 関数もメモ化して、子コンポーネントの不要な再描画を防ぐ
  const handleClick = useCallback((id) => {
    console.log('Clicked', id);
  }, []);

  return ;
}
